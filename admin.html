Kết nối GitHub

Token chỉ lưu trong trình duyệt của bạn (nếu chọn “Nhớ”), không gửi đi đâu ngoài GitHub. Tạo token: GitHub → Settings → Developer settings → Fine-grained tokens → chỉ chọn repo ban-do-dau-gia, quyền Contents: Read and write.

Dán dữ liệu từ Google Sheets vào ô dưới (Google Sheet → bấm ô A1 → Ctrl+A → Ctrl+C → bấm vào ô dưới → Ctrl+V): Phải có hàng tiêu đề. Dòng trùng mã → cập nhật, mã mới → thêm.

Dán cả bảng từ Google Sheets: chọn từ ô A1 (có hàng tiêu đề id, ngay, tinh…) → Ctrl+C → bấm vào ô bất kỳ ở đây → Ctrl+V. Cột được khớp theo tên; dòng trùng mã thì cập nhật, mã mới thì thêm.
Gõ thẳng vào ô như Excel. Enter xuống dòng dưới, Tab sang ô bên phải. Có thể sao chép nhiều ô từ Excel/Google Sheets rồi dán: dán vào một dòng mới (nút ＋ Thêm dòng) thì mỗi dòng dán thành một phiên mới; dán vào dòng có sẵn thì ghi đè các ô bên dưới như Excel. Dòng vàng = đã sửa, xanh = mới, đỏ = sẽ xóa. Chỉ khi bấm Lưu tất cả mới ghi lên GitHub.

Thêm phiên mới

Giá dùng dấu chấm thập phân (56.08). Bấm lên bản đồ bên phải để lấy tọa độ.

Chọn vị trí

Bấm vào bản đồ để đặt điểm; kéo điểm để chỉnh. Chuyển sang “Ảnh vệ tinh” để tìm khu đất.

Giao diện – màu sắc
